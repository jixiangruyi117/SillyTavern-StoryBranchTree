# 剧情分支树（SillyTavern Story Branch Tree）

在**同一条单人聊天记录**中创建和管理多条剧情路线：从任意楼层分叉、在分支里继续分支，也能切回其他路线接着聊。

> [!IMPORTANT]
> 这是用户维护的 SillyTavern 第三方界面扩展，不属于 SillyTavern 官方项目，也不修改酒馆核心文件。

## 核心功能

- **从任意楼层分叉**：同一个分叉点可创建多条路线，子路线也能继续分叉。
- **重说回复独立成线**：从当前显示的 AI 回复建立路线；历史楼层可切换回复，之后仍能回到对应路线。
- **切换路线并继续游玩**：确认后切换到主线或任意分支，原路线后续内容会保留。
- **可视化剧情树**：全屏查看路线、分叉点和终点；支持详细/简略视图、缩放、平移、定位、整理和拖动布局。
- **备注和摘要**：为路线、分叉点添加名称、摘要或备注，查看末楼内容。
- **只保留一条聊天记录**：所有路线都保存在当前聊天记录中，随聊天导出和导入。
- **本地运行**：分支树本身不调用模型、不连接外部服务；仅支持单人角色聊天，不支持群聊。

## 安装

在 SillyTavern 的 **扩展 → 安装扩展** 中粘贴仓库地址：

```text
https://github.com/jixiangruyi117/SillyTavern-StoryBranchTree
```

安装后刷新页面。点击聊天输入框左侧的魔法棒，在菜单中选择 **剧情分支树** 打开全屏树状图。在任意消息旁点击 **分支** 并确认，即可创建路线。树中点击路线名可查看详情并确认切换；删除路线也需要确认。

画布支持滚轮缩放和拖动平移；触屏设备可双指捏合缩放。点击 **定位当前** 将正在聊天的路线移到画布中央，点击 **整理布局** 重新排列节点。路线末尾楼层可查看正文，触屏长按或鼠标拖动可调整位置。

## 路线数据与记忆隔离

分支图保存在当前聊天的 `chat_metadata.story_branch_tree` 中。酒馆聊天数组始终显示当前选中的一条线性路线；切换时，扩展从共享前文和路线后缀重建聊天数组。路线使用稳定消息标识定位分叉点；原生重说回复也分别记录标识和已选择的回复。

分支树会按路线保存原生 `is_hidden` / `is_system` 状态，以及**已注册适配器明确声明**的消息字段和聊天元数据字段。分叉时继承当前已有的数据；之后不同路线独立更新。声明的数据随聊天导出和导入。正文仍使用共享前文与分支后缀保存，因此长期、多路线聊天会增加单个聊天文件的体积。

分支树不自动探测、调用或改写特定记忆插件的内部实现。插件作者可阅读[通用路线记忆接口教程](docs/MEMORY_ADAPTER_API.md)，主动注册适配器、声明自己拥有的字段，并在路线切换时恢复自己的缓存。未接入接口的插件继续按其原有逻辑运行；其聊天级缓存、外部数据库或向量索引不会自动按路线隔离。没有逐楼记录的历史摘要也无法凭空还原到分叉点。

通用接口包括路线查询、路线消息读取、字段快照、切换钩子和后台任务凭证。没有分支时，不会自动启动记忆适配器任务或模型请求；未使用接口的普通聊天流程不受适配代码影响。字段或恢复职责由多个适配器重复声明时，注册会被拒绝。

### 路线编号、重说和聊天状态

路线编号用于树图展示，实际关系由稳定路线 ID 保存。普通分支按父路线、分叉楼层和同点的路线序号排列；重说路线会标明回复楼层。同一分叉点创建的多个子路线分别编号，嵌套分支按各自父路线继续排列。

普通 **分支** 从当前消息的活动回复之后继续；从历史 AI 回复创建重说路线时，该回复成为新路线的起始楼层。历史回复箭头由分支树接管：切换到尚未续写的回复后，发送下一条消息并确认，才会为它创建路线；切回已有回复时会恢复该回复原来的后续路线。

路线切换会恢复消息本身的数据、路线记忆快照以及各路线的 `chat_metadata.variables`，再重建消息界面并发送酒馆的“聊天已加载”事件。重说回复中按 `variables[swipe_id]` 保存的状态随对应回复保留；未保存为逐楼或逐回复状态的数据无法还原到过去。

## 当前限制

- 仅支持单人角色聊天，不支持群聊和临时助手聊天。
- 分支共用同一个聊天 ID；未接入路线 API 的扩展若按聊天 ID 或外部存储维护状态，其数据仍可能被不同路线共用。
- 删除或修改共享前文可能影响引用该内容的其他路线；请使用分支树管理路线，不要直接删除共享楼层。
- 旧摘要若没有逐楼或可回溯数据，无法自动重建分叉前的准确记忆。
